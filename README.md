# 🎵 Music Player

یک موزیک پلیر ساده و کاربردی که با استفاده از **HTML، CSS و JavaScript** ساخته شده است.

این پروژه به عنوان یکی از پروژه‌های تمرینی من برای تقویت مهارت‌های **JavaScript و کار با DOM** ساخته شده و در آن با قابلیت‌های مختلف مربوط به پخش موسیقی و کنترل عناصر صفحه کار کردم.

## ✨ امکانات

* ▶️ پخش و توقف موسیقی
* ⏭️ رفتن به آهنگ بعدی
* ⏮️ رفتن به آهنگ قبلی
* ⏩ جلو رفتن ۱۰ ثانیه‌ای
* ⏪ عقب رفتن ۱۰ ثانیه‌ای
* 🖼️ نمایش تصویر مربوط به هر آهنگ
* 🎵 نمایش نام آهنگ و خواننده
* 🎧 پشتیبانی از چند آهنگ
* 📱 طراحی واکنش‌گرا
* 🎨 رابط کاربری ساده و مینیمال

## 🛠️ تکنولوژی‌های استفاده شده

* **HTML5**
* **CSS3**
* **JavaScript**
* **Font Awesome**

## 📚 چیزهایی که در این پروژه تمرین کردم

در طول ساخت این پروژه با موارد زیر بیشتر کار کردم:

* کار با DOM
* Event Listenerها
* کار با تگ `<audio>`
* آرایه‌ها و Objectها در JavaScript
* نوشتن و استفاده از Functionها
* شرط‌ها
* تغییر محتوای HTML به صورت داینامیک
* تغییر تصویر، نام آهنگ و نام خواننده
* مدیریت وضعیت Play و Pause
* ساخت کنترل‌های مربوط به موسیقی

## 🚀 نحوه اجرا

برای اجرای پروژه:

1. Repository را Clone کنید.
2. وارد پوشه پروژه شوید.
3. فایل `index.html` را در مرورگر باز کنید.

همچنین می‌توانید پروژه را با استفاده از **Live Server** در VS Code اجرا کنید.
